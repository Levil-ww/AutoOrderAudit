# AutoOrderAudit V2.3.0

本次参考 `F:\Fangguo-Auto-v2.0` 当前源码补齐功能（该目录当前版本实际为 V2.4.0），AutoOrderAudit 发布版本按要求设为 V2.3.0。版本统一维护在 `_version.py`，GUI 标题、版本标记及命令行审单横幅动态读取。

## 新增功能

| 功能 | 实现与使用 |
| --- | --- |
| GUI 布局 | 与参考项目保持一致的深色标题栏、三张状态卡片、深色着色日志、底部操作按钮；配置弹窗沿用同一布局与配色 |
| 运行计时 | 日志区显示运行时间，审单、推单、监控时启动，暂停/结束时停止，清空日志重置 |
| 赠品配置 | “赠品配置”维护名称、别名、商品 ID、SKU ID、商家编码；解析和赠品行构建共用配置，新增南瓜赠品 |
| 正常发与赠品 | “正常发/特定”备注可处理赠品，主商品编码及数量保持原样；合并订单按子订单保留归属 |
| 快递配置 | 优先级：备注关键词（最长优先）→店铺→平台→省份；支持刷新店铺列表并缓存，删除自定义快递同步清理引用 |
| 自适应监控 | 新订单等待备注完善后处理，空闲自动延长轮询间隔；仅审查已就绪订单，支持暂停、停止以及仅有待推送订单时推单 |
| 订单推送 | “开始推单”独立执行；监控审单后自动推单。合并待推送/待整理来源并去重，付款满 30 分钟才允许提交 |
| 推单校验 | 拦截待确认、指定日期发货、退款中、缺失详情/付款时间、解码失败、主商品编码/数量不匹配、仅赠品或补差价不打印订单；快递修改失败阻止推送 |
| 推单材质限制 | 防辣椒油、丝圈、泡泡绒兔毛不允许自动推送；2026-10-22 参考项目增量同步新增浴室吸水科技布（正常审单不受影响） |
| 查询与停止 | 分页查询，业务失败不再当作空订单；停止信号在订单边界与推单提交前检查，停止监控后不启动后续推单 |
| 备注扩展 | 中文复合数量（十一、二十一等）、数量前置、“成品”现货前缀、多尺寸花型材质继承、自定义赠品识别及赠品不发货同义写法 |
| 手工单接口 | 适配器补充手工商品行识别和清理方法，未增加自动清理行为；不在验证中执行真实删除 |

推单 API 的 `code=0` 表示异步任务受理；随后查询工厂待审状态核验，逐单最终结果以 ERP 为准。
